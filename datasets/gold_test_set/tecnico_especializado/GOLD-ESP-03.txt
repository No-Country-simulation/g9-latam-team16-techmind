TITULO: Configuración HCL Avanzada en Terraform: Clúster RDS Multi-AZ y Storage Encryption con KMS
CATEGORIA_ESPERADA: Cloud

Contexto de Infraestructura Desplegada Automatizada:\nLa infraestructura inmutable en entornos de Misión Crítica exige un control programático riguroso y versionado. El siguiente código de Terraform (Lenguaje HCL) ejemplifica el aprovisionamiento de una base de datos relacional robusta (Amazon RDS para PostgreSQL). El script asegura la alta disponibilidad Multi-AZ y obliga la criptografía de los volúmenes de datos en reposo mediante una llave simétrica gestionada por el servicio KMS de AWS, bloqueando el despliegue si se vulnera la compliance corporativa de seguridad de datos (Infosec).\n\nDeclaración Declarativa Terraform:\n```hcl\nresource \"aws_kms_key\" \"db_encryption_key\" {\n  description             = \"KMS Master Key para cifrado de almacenamiento RDS Postgres\"\n  enable_key_rotation     = true\n  deletion_window_in_days = 30\n  tags = { Environment = \"production\", Project = \"AyniKortex\" }\n}\n\nresource \"aws_db_instance\" \"primary_database\" {\n  identifier             = \"aynikortex-prod-db-cluster\"\n  engine                 = \"postgres\"\n  engine_version         = \"15.4\"\n  instance_class         = \"db.r6g.large\"\n  allocated_storage      = 250\n  max_allocated_storage  = 1000\n  storage_type           = \"io1\"\n  iops                   = 3000\n  \n  db_name                = \"aynikortex_main\"\n  username               = var.db_admin_username\n  password               = var.db_admin_password\n  \n  multi_az               = true\n  publicly_accessible    = false\n  storage_encrypted      = true\n  kms_key_id             = aws_kms_key.db_encryption_key.arn\n  \n  vpc_security_group_ids = [aws_security_group.db_sg.id]\n  db_subnet_group_name   = aws_db_subnet_group.private_subnet_group.name\n  \n  backup_retention_period = 14\n  skip_final_snapshot     = false\n  final_snapshot_identifier = \"aynikortex-prod-db-final-snap\"\n}\n```
