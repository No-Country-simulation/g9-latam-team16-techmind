TITULO: Manifestos Declarativos YAML Avanzados en Kubernetes: Deployment y HorizontalPodAutoscaler
CATEGORIA_ESPERADA: DevOps

Contexto Técnico:\nEn entornos cloud, el aprovisionamiento manual de contenedores es ineficiente y propenso a errores. En AyniKortex, toda la infraestructura se define de forma declarativa mediante manifiestos YAML que el Control Plane de Kubernetes reconcilia constantemente para garantizar la resiliencia operativa y la escalabilidad de nuestras APIs críticas.\n\nCódigo de Configuración K8s:\n```yaml\napiVersion: apps/v1\nkind: Deployment\nmetadata:\n  name: aynikortex-auth-service\n  namespace: production\n  labels:\n    app: auth-service\n    tier: backend\nspec:\n  replicas: 3\n  strategy:\n    type: RollingUpdate\n    rollingUpdate:\n      maxSurge: 2\n      maxUnavailable: 0\n  selector:\n    matchLabels:\n      app: auth-service\n  template:\n    metadata:\n      labels:\n        app: auth-service\n    spec:\n      containers:\n      - name: auth-api\n        image: ecr.aws/aynikortex/auth-service:v3.2.1\n        ports:\n        - containerPort: 8080\n        env:\n        - name: SPRING_PROFILES_ACTIVE\n          value: \"prod\"\n        resources:\n          requests:\n            memory: \"512Mi\"\n            cpu: \"250m\"\n          limits:\n            memory: \"1Gi\"\n            cpu: \"1000m\"\n        livenessProbe:\n          httpGet:\n            path: /actuator/health/liveness\n            port: 8080\n          initialDelaySeconds: 40\n          periodSeconds: 15\n```
