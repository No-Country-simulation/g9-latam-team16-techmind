TITULO: Arquitectura de Serverless Computing en Google Cloud Platform con Cloud Run y Firestore
CATEGORIA_ESPERADA: Cloud

El modelo computacional Serverless permite a las organizaciones enfocar sus recursos exclusivamente en el valor de negocio del código fuente, transfiriendo la administración, mantenimiento y autoescalado de servidores a la infraestructura gestionada de Google Cloud.\n\nEjecución de Contenedores con Cloud Run:\nLos microservicios de AyniKortex se empaquetan en imágenes de contenedor ligeras basadas en Alpine Linux. Google Cloud Run gestiona la ejecución de las instancias, escalando de manera automática desde cero (Scale to Zero) durante periodos de inactividad hasta cientos de instancias concurrentes ante ráfagas masivas de tráfico HTTP.\n\nBase de Datos y Almacenamiento Distribuido:\nLa persistencia de datos orientada a documentos utiliza Google Cloud Firestore en modo Datastore, garantizando consistencia fuerte y escalabilidad horizontal automática. En el marco de la modernización de la plataforma, este componente fue refactorizado para garantizar un rendimiento óptimo bajo cargas de trabajo pesadas. El equipo de arquitectura técnica documentó cada decisión de diseño para asegurar que el despliegue a producción cumpla con todos los estándares de calidad ISO y las regulaciones corporativas vigentes de protección de datos (GDPR).
