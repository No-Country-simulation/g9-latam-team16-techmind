TITULO: Microservicio Reactivo de Backend en Spring Boot 3 con Acoplamiento a Data Lakes distribuidos S3 e Identidad KMS
CATEGORIA_ESPERADA: Backend

Flujo de Datos y Abstracción de Código: Construimos una infraestructura de Application Programming Interface (API) de excepcional rendimiento, desarrollada en su integridad utilizando el ecosistema de Java 21 LTS y el framework reactivo de Spring Boot (WebFlux). Esta pieza de software (Backend) se desliga de la base de datos relacional tradicional y se conecta directamente a un almacenamiento masivo de objetos en la nube de Amazon Web Services (AWS S3) comportándose como un potente Data Lake. La lógica del backend implementa una serie de consultas directas, proyecciones asíncronas y agregaciones analíticas sobre inmensos volúmenes de archivos parquet crudos. Para garantizar el absoluto hermetismo de los datos personales (PII) bajo las normas GDPR corporativas, los flujos de lectura y escritura ejecutan llamadas criptográficas interconectándose en milisegundos con las claves simétricas del servicio AWS KMS, orquestado todo bajo políticas IAM de extremo menor privilegio que el framework debe firmar criptográficamente antes de cada Request.
