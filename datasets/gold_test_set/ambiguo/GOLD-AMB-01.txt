TITULO: Arquitectura Híbrida de Inferencia de Inteligencia Artificial Serverless mediante AWS Lambda y GitHub Actions CI/CD
CATEGORIA_ESPERADA: AI/ML

Contexto Operativo Multi-Dominio: En esta compleja solución arquitectónica, los diferentes dominios tecnológicos convergen en un único microservicio. Logramos integrar exitosamente un modelo fundacional de clasificación semántica, que fue entrenado previamente con scripts intensivos en Python y PyTorch, empaquetándolo minuciosamente dentro de un contenedor Docker liviano y altamente optimizado. Sin embargo, el centro del proceso radica en cómo esta imagen contenedorizada se provisiona y orquesta de forma totalmente desatendida. Una compleja tubería (pipeline) de Integración Continua y Despliegue Continuo (CI/CD) orquestada en los servidores de GitHub Actions toma el código fuente, lo compila sin intervención humana y desencadena el paso a producción. Finalmente, el artefacto resultante se despliega de forma nativa como una función Serverless elástica en el entorno de AWS Lambda. Esta función sin servidor permanece inactiva, reduciendo costos drásticamente, hasta que es invocada transaccionalmente por eventos de peticiones HTTP en tiempo real provenientes del servicio administrado de Amazon API Gateway, logrando alta disponibilidad global.
