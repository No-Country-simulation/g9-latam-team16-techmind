TITULO: Patrón MVC y Arquitectura de Controladores RESTful con Manejo Global de Excepciones en Spring Boot
CATEGORIA_ESPERADA: Backend

Contexto Arquitectónico: Un backend robusto debe no solo exponer funcionalidades a través de endpoints, sino también garantizar que cualquier fallo interno sea capturado y traducido en respuestas HTTP estándar, sin filtrar información sensible del sistema al cliente (Stack Traces).\n\nDiseño del Backend: La capa de exposición de AyniKortex se implementó utilizando Spring Boot MVC bajo estrictos principios RESTful. Los controladores Java, marcados con la anotación @RestController, actúan únicamente como orquestadores que delegan la lógica de negocio a los servicios de dominio. Utilizamos MapStruct para la conversión eficiente entre Entidades JPA y Data Transfer Objects (DTOs), junto con Jakarta Validation (@Valid) para validar las cargas útiles entrantes. Fundamentalmente, incorporamos un @ControllerAdvice que intercepta todas las excepciones lanzadas en tiempo de ejecución, transformándolas en objetos JSON estructurados con códigos HTTP apropiados (como 400 Bad Request o 404 Not Found), estandarizando así el contrato de comunicación con el frontend.
