TITULO: Pipeline de Integración Continua (CI) con GitHub Actions y Análisis de Calidad en AyniKortex
CATEGORIA_ESPERADA: DevOps

Contexto de Negocio: En AyniKortex, la velocidad de entrega de nuevas funcionalidades es crítica para mantener la ventaja competitiva en el mercado de plataformas de recursos humanos. Sin embargo, esta velocidad no debe comprometer la calidad del código, razón por la cual el equipo de plataforma ha priorizado la automatización del flujo de despliegue.\n\nImplementación Técnica: Para lograr una entrega continua confiable, hemos configurado un pipeline de GitHub Actions que se dispara automáticamente ante cada push o pull request dirigido a la rama main. Este flujo automatizado no solo compila el código fuente y ejecuta las pruebas unitarias con cobertura superior al 85%, sino que integra SonarQube para el análisis estático de vulnerabilidades y code smells. Tras la validación exitosa, el pipeline procede a empaquetar el microservicio de autenticación en una imagen de contenedor Docker, la cual es versionada y empujada a un repositorio privado en Amazon Elastic Container Registry (ECR), dejando el artefacto listo para la orquestación posterior.
