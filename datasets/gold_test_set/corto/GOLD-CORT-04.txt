TITULO: Implementación de Autenticación Stateless y Seguridad de APIs con JSON Web Tokens (JWT)
CATEGORIA_ESPERADA: Security

Requisito de Seguridad: Mantener el estado de las sesiones de miles de usuarios concurrentes en la memoria del servidor no es escalable bajo una arquitectura de microservicios efímeros. Se requería un mecanismo seguro y descentralizado para validar la identidad de las peticiones web.\n\nSolución de Autenticación: La arquitectura de seguridad del backend se rediseñó utilizando el estándar JSON Web Tokens (JWT) integrado con Spring Security. Al iniciar sesión, el servidor genera un token codificado que incluye claims específicos del usuario, firmado digitalmente mediante un algoritmo asimétrico RSA-256 para evitar su manipulación. El cliente almacena este token de manera segura y lo adjunta en el encabezado 'Authorization: Bearer' de cada solicitud HTTP subsiguiente. Un filtro de seguridad intercepta estas llamadas, verifica matemáticamente la firma del JWT contra la llave pública sin necesidad de consultar la base de datos, logrando una arquitectura 100% Stateless que mitiga vulnerabilidades de suplantación.
