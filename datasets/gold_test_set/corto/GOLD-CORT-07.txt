TITULO: Automatización Declarativa de Clusters EKS y Grupos de Autoescalado en AWS mediante Terraform
CATEGORIA_ESPERADA: Cloud

Necesidad de Infraestructura: La gestión manual de recursos en la nube conduce invariablemente a la inconsistencia entre entornos (Drift de configuración) y dificulta la recuperación ante desastres en arquitecturas de alta disponibilidad.\n\nAprovisionamiento Cloud: Adoptamos un enfoque estricto de Infraestructura como Código (IaC) utilizando Terraform para aprovisionar el entorno base de Kubernetes. El código declarativo de Terraform define un cluster de Elastic Kubernetes Service (Amazon EKS) distribuido a lo largo de tres Zonas de Disponibilidad (Multi-AZ) para garantizar redundancia. Para optimizar los costos computacionales, se configuraron Managed Node Groups integrados con Auto Scaling Groups (ASG) de AWS. Estos grupos monitorizan métricas críticas de reserva de CPU y Memoria, añadiendo o retirando dinámicamente instancias EC2 del pool de nodos subyacente según las demandas de las cargas de trabajo desplegadas en AyniKortex.
